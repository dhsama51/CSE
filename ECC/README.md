# Elliptic-Curve Arithmetic over P-256

A C implementation of elliptic-curve point operations and scalar-multiplication algorithms over the NIST P-256 curve.

The implementation builds directly on the repository's eight-word, 256-bit arithmetic rather than using an external ECC or big-number library.

## Implemented Operations

### Point Representation and Operations

- affine-affine point addition;
- Jacobian-affine point addition;
- Jacobian-Jacobian point addition;
- point doubling in affine coordinates;
- point doubling in Jacobian coordinates;
- Jacobian-to-affine coordinate conversion;
- handling of the point at infinity and exceptional point-operation cases.

### Scalar Multiplication

- left-to-right binary method in Jacobian coordinates;
- left-to-right binary method in affine coordinates;
- right-to-left binary method in affine coordinates;
- non-adjacent form (NAF);
- width-\(w\) non-adjacent form (wNAF);
- sliding-window method;
- fixed-window method;
- fixed-base comb method.

### Multi-Scalar Multiplication

- Shamir's trick;
- interleaving method.

## Files

| File | Purpose |
|---|---|
| `ecadd.[ch]` | Point-addition formulas for affine and Jacobian coordinates |
| `ecdbl.[ch]` | Point-doubling formulas |
| `eccsm.[ch]` | Scalar- and multi-scalar-multiplication algorithms |
| `eccGlobal.[ch]` | Curve-related helpers and Jacobian-to-affine conversion |
| `bigInt*.c`, `bigInt*.h` | 256-bit and P-256 field arithmetic used by ECC |
| `main.c` | Point-operation tests and scalar-multiplication vector generation |
| `TV_Scalar.txt` | 10,000 scalar inputs |
| `TV_SM.txt` | Reference scalar-multiplication results |
| `TV_*_LDH.txt` | Outputs generated by individual algorithms |

`eccsm_045400.c` and `main_old_test.c` are retained development snapshots and are not included in the current `Makefile`.

## Build and Run

```bash
make
./main.exe
```

To clean generated files:

```bash
make clean
```

The test driver uses commented function calls to select a point operation or scalar-multiplication method. In `ECCSMTest()`, select one algorithm and its corresponding output file, then rebuild.

## Validation

The scalar-multiplication experiment uses the P-256 base point with 10,000 values from `TV_Scalar.txt`. Each computed point is converted to affine coordinates and written to an algorithm-specific output file for comparison with `TV_SM.txt`.

The current `main.c` contains local Windows absolute paths for the input and output files. Update them to relative paths or to the local clone location before running the vector-generation test.

## Scope

This code was written to study how coordinate systems and scalar-multiplication strategies change an ECC implementation. It has not been audited for constant-time execution, side-channel resistance, or production use.
